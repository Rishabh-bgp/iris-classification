# Data
* `data/iris.data` — the UCI Iris file (150 rows, 4 numeric features in cm, 3 species × 50). `web/iris.json` is the
  same data as JSON for the demo chart.
* Source: Fisher, R. A. (1936). *Iris*. UCI Machine Learning Repository. doi:[10.24432/C56C76](https://doi.org/10.24432/C56C76)
  — https://archive.ics.uci.edu/dataset/53/iris
* Licence: **CC BY 4.0** (stated on the UCI page) → redistributed here with attribution.
* Quality: 0 missing values; 3 duplicate rows (kept).
* Features: sepal length, sepal width, petal length, petal width.
